# MagicBox M301 · ESP32-C5

[English](README.md) · [BSP 与来源说明](../../../../../../boards/m301-c5-rtc-v1-5g/README.zh_CN.md)

用户已确认型号为 M301。配置名按来源板型区分，实物 PCB 版本仍待核对；旧 HW1.2.0 参考配置独立保留。引脚和电源配置已与 folotoy-firmware-idf 的 `8c013c923b59f1123e762880100d62ccf7005907` 提交中 `magicbox_rtc_v1_5G` 系列核对。

## 构建

激活 ESP-IDF 6.1 后，在仓库根目录执行：

```sh
./tools/build_xiaozhi.sh --board m301-c5-rtc-v1-5g
```

| 配置项 | 值 |
|---|---|
| 构建版本 | `folotoy-magicbox-m301-c5-rtc-v1-5g` |
| 板型 / OTA 标识 | `magicbox-m301-c5-rtc-v1-5g` |
| 芯片与存储 | ESP32-C5；已识别设备为 16 MB Flash、4 MB Quad PSRAM |
| 服务 | `https://magic.folotoy.cn/xiaozhi/ota/` |
| 配网热点 | `FoloToy-XXXX`，不预填 Wi-Fi |
| 应用版本 | MagicBox `0.1.0` |

构建脚本按完整硬件配置隔离源码缓存和生成文件，拒绝 C5 配置搭配 M09 构建版本，反之亦然。元数据包含配置 ID、构建版本、板型及镜像校验值。构建不会刷机。

## 操作与实现

| 操作 | 行为 |
|---|---|
| Voice（GPIO2） | 按住说话，松开发送 |
| Mode（GPIO3） | 单击控制会话；长按一秒进入配网 |
| 旋钮（GPIO6） | ADC 读数越大音量越大；平滑采样，不连续写 NVS |
| RGB（GPIO27） | 待机绿、录音红、播放蓝、网络设置黄 |

I2C、I2S/ES8311、AXP2101、按键、旋钮和 RGB 均由 BSP 单独持有，应用通过适配层对接既有协议和音频服务。音频为 24 kHz、16 位单声道，麦克风使用编码器 30 dB 增益，不套用 M09 数字麦克风的 8 倍转换。启动音量按实体旋钮位置读取；电池信息来自 AXP2101。

首版 C5 适配未启用自动 PMU 休眠、晃动唤醒、外接 Mode 映射、唤醒词、AEC、显示屏和摄像头。RTC 与 GX8002 保留为可选 BSP API；本应用不设置闹钟、不升级唤醒芯片。不能把中断定义或编译通过当作这些功能的实机验收。

## 分区与验收

`partitions/folotoy-magicbox-m301-c5.csv` 与指定源码及设备只读分区表一致：factory `0x210000`、app0 `0x610000`、app1 `0xA10000`，各 4 MB；独立产品身份 NVS 为 `0xF20000`。不能使用 M09 的应用烧录地址。

此次代码变更不刷机、不清除配置、不替换原厂镜像，也不激活设备。后续获得明确授权后，须先核对实物 PCB、实际启动分区，私有备份原应用、设置和身份，检查 C5 镜像大小与校验值，仅更新获准的应用分区。保留分区表、原厂应用、文件系统和身份 NVS，不向量产设备写入合并镜像。

待实机验收：启动与 PSRAM/外设检测、提示音、Voice 录放音、Mode、旋钮方向及两端音量、配网、激活、对话、重连、电池/USB 行为、重启保存。M09 的历史实机结果不适用于 M301。
