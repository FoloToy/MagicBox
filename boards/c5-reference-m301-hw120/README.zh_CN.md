# 旧 C5 HW1.2.0 参考

[English](README.md)

保留 [magicbox-c5 原始来源](https://github.com/FoloToy/magicbox-c5/tree/f889d36f721dce7c503cdacf67f18de12a082ca2) 的 M301 / HW1.2.0 参考实现，SDK 为 ESP-IDF 5.5.3，GX8002 使用原驱动的 ALDO1/ALDO3 别名。本项目没有完成这份配置的实机验收，也不会自动选择它来适配新接入的 M301。

本次用户指定的 firmware-idf 板型使用 ALDO4/BLDO1，另建 [M301 RTC-v1-5G 配置](../m301-c5-rtc-v1-5g/README.zh_CN.md)，实物 PCB 版本待核对。不能仅凭 GPIO 相同合并硬件版本。
