# Legacy C5 HW1.2.0 reference

[简体中文](README.zh_CN.md)

Historical [magicbox-c5 source](https://github.com/FoloToy/magicbox-c5/tree/f889d36f721dce7c503cdacf67f18de12a082ca2), source model M301 / HW1.2.0. Retained on ESP-IDF 5.5.3 with its original ALDO1/ALDO3 GX8002 driver aliases. No physical unit has been accepted against this profile here. It does not select the newly connected M301 automatically.

The owner's cited firmware-idf board uses ALDO4/BLDO1 instead. Use the separate [M301 RTC-v1-5G profile](../m301-c5-rtc-v1-5g/README.md) for that source, with physical PCB verification pending. Do not infer identical hardware from matching GPIOs.
